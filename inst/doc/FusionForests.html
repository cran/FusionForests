Fusing a randomised trial and real-world data

Tijn Jacobs

Introduction

We introduce the FusionForests package. It estimates heterogeneous treatment effects on survival from a randomised controlled trial (RCT) and real-world data (RWD) from an observational study. An RCT alone rarely suffices, because RCTs are often small. RWD are often more abundant but may suffer from unmeasured confounding. This confounding biases the estimated treatment effects. FusionForests combines both sources. The RCT protects the estimates against confounding, and the RWD contribute a larger sample. Jacobs, van der Pas and van Wieringen (2026) develop the methodology.

For a patient with covariates \(x\), treatment \(A\) and source \(S\) (1 = RCT, 0 = RWD), the log survival time follows an accelerated failure time model: \[ \log T = m_0^{\mathrm{sh}}(x) + (1 - S)\, d(x) + A\, \tau(x) + (1 - S)\, A\, c(x) + \varepsilon . \] The error \(\varepsilon\) has mean zero. It follows a hierarchical Dirichlet process mixture with a scale per source. Each of the four functions receives its own Bayesian additive regression tree (BART) prior (Chipman et al., 2010). The four functions are contrasts of the conditional mean log survival time. We write this mean as follows: \[ \mu(x, a, s) = \mathrm{E}[\log T \mid X = x, A = a, S = s]. \] The shared baseline is the mean log survival time of untreated RCT patients: \[ m_0^{\mathrm{sh}}(x) = \mu(x, 0, 1). \] The deviation is the difference between the RWD and RCT baselines: \[ d(x) = \mu(x, 0, 0) - \mu(x, 0, 1). \] The conditional average treatment effect (CATE) is the causal effect on the log survival time: \[ \tau(x) = \mathrm{E}[\log T(1) - \log T(0) \mid X = x] = \mu(x, 1, 1) - \mu(x, 0, 1), \] where \(T(a)\) is the survival time under treatment \(a\). The CATE is common to both sources. The confounding function is the bias of the treatment contrast in the RWD: \[ c(x) = \mu(x, 1, 0) - \mu(x, 0, 0) - \tau(x). \] Jacobs, van der Pas and van Wieringen (2026) show that this decomposition holds and that \(\tau\) and \(c\) are identified. Their result requires standard assumptions on the causal structure and the censoring mechanism, randomisation in the RCT and transportability of the CATE across sources. The paper states these assumptions in full.

We illustrate the package on a semi-synthetic data set. We describe the data, fit the model and summarise the posterior of the treatment effect, the confounding function and the error model. The outcomes are simulated, so we can compare every estimate with the truth.

Data

The data set breast_fusion combines an RCT of 686 patients with RWD on 2,982 patients. The covariates are derived from the GBSG2 trial (Schumacher et al., 1994) and the Rotterdam tumour bank (Royston and Altman, 2013). The datasets are distributed with the survival package. The relapse-free survival times are simulated, and the RCT treatment is randomised. The RWD treatment is the real, non-random treatment assignment of the Rotterdam cohort. This assignment depends in part on year of surgery and chemotherapy, which breast_fusion omits. The RWD are subject to unmeasured confounding. The companion data set breast_fusion_truth contains the true CATE and the omitted confounders. The data describe no real treatment or real clinical effect.

Fitting the model

FusionForest() takes covariate matrices, treatment and source indicators and the outcome. We supply log survival times with their event indicators. The test set determines where the posterior is evaluated. We pass all patients as the test set, so that we can later summarise either source. The argument store_posterior_sample = TRUE keeps the posterior draws that the summary functions need. We run 5,000 burn-in and 5,000 posterior iterations, the package default.

X      <- as.matrix(breast_fusion[, x_names])
A      <- breast_fusion$A
S      <- breast_fusion$S
y      <- log(breast_fusion$time)
status <- breast_fusion$status
is_rct <- S == 1
is_os  <- S == 0

set.seed(42)
fit <- FusionForest(
  y = y, status = status,
  X_train_control = X, X_train_treat = X,
  treatment_indicator_train = A, source_indicator_train = S,
  X_test_control = X, X_test_treat = X,
  treatment_indicator_test = A, source_indicator_test = S,
  outcome_type = "right-censored", timescale = "log",
  N_post = 5000, N_burn = 5000,
  store_posterior_sample = TRUE, verbose = FALSE
)

Treatment coding

The argument treatment_coding sets how the treatment indicator enters the model. A coded treatment \(b\) replaces \(A\) in front of \(\tau\) and \(c\): \[ \log T = m_0^{\mathrm{sh}}(x) + (1 - S)\, d(x) + b\, \{\tau(x) + (1 - S)\, c(x)\} + \varepsilon . \] The package offers three codings.

treatment_coding \(b\) \(m_0^{\mathrm{sh}}\) and \(d\) describe
"binary" \(A\) the untreated arm, as in the paper
"centered" (default) \(A - 1/2\) the average of the two arms
"adaptive" \(A - \pi(x)\) the average of the two arms, weighted by the propensity score \(\pi(x)\)

The functions \(\tau\) and \(c\) keep their meaning under every coding. Under the binary coding, only treated patients inform \(\tau\). Under the centred coding, both arms inform \(\tau\). For this reason the centred coding is the default. The adaptive coding follows Hahn et al. (2020). It requires estimated propensity scores through propensity_train and propensity_test. fusion_estimand() accounts for the coding of the fit, so the estimands below have the same meaning under every coding.

Single-source comparators

We compare the fusion fit with two single-source analyses. ShrinkageTrees::CausalShrinkageForest(), from the ShrinkageTrees package, fits a causal forest to one source. We match its priors to those of FusionForest(). The RCT-only fit is unbiased but may have a large posterior variance. The RWD-only fit includes more patients, which lowers its posterior variance. Its treatment effects are biased by the unmeasured confounders.

fit_single <- function(rows) {
  ShrinkageTrees::CausalShrinkageForest(
    y = y[rows], status = status[rows],
    X_train_control = X[rows, ], X_train_treat = X[rows, ],
    treatment_indicator_train = A[rows],
    X_test_control = X, X_test_treat = X, treatment_indicator_test = A,
    outcome_type = "right-censored", timescale = "log",
    number_of_trees_control = 200, number_of_trees_treat = 100,
    prior_type_control = "standard", prior_type_treat = "standard",
    local_hp_control = 1 / (2 * sqrt(200)),
    local_hp_treat = 0.5 / (2 * sqrt(100)),
    power_control = 2, power_treat = 3,
    N_post = 5000, N_burn = 5000,
    store_posterior_sample = TRUE, verbose = FALSE
  )
}
set.seed(42)
fit_rct <- fit_single(is_rct)
fit_os  <- fit_single(is_os)

Treatment effects

Acceleration factor

The acceleration factor \(\exp\{\tau(x)\}\) multiplies the survival time of a patient with covariates \(x\) under treatment. fusion_estimand() returns its posterior draws at each test row. With population_average = TRUE it averages over the test rows. The average uses Bayesian-bootstrap weights (Rubin, 1981), which propagate uncertainty about the covariate distribution. Our test set contains all patients of both sources.

Table 1 evaluates the individual CATEs on the log-time scale. Bias and root mean squared error (RMSE) compare the posterior mean with the true CATE. The posterior variance is averaged over patients. Coverage is the proportion of patients whose 95% credible interval contains the true CATE.

tau_draws <- lapply(af_draws, log)
tau_true  <- breast_fusion_truth$tau

cate_metrics <- function(d, rows) {
  d   <- d[, rows]
  est <- colMeans(d)
  lo  <- apply(d, 2, quantile, 0.025)
  hi  <- apply(d, 2, quantile, 0.975)
  err <- est - tau_true[rows]
  c(bias     = mean(err),
    rmse     = sqrt(mean(err^2)),
    post_var = mean(apply(d, 2, var)),
    coverage = mean(lo <= tau_true[rows] & tau_true[rows] <= hi))
}

Survival difference

The survival difference \(S_1(t \mid x) - S_0(t \mid x)\) compares the survival probabilities at time \(t\) under treatment and control. It depends on the baseline and the error distribution as well as on \(\tau\). fusion_estimand() evaluates it in closed form at a time time, measured on the original time scale. The argument target_source selects the baseline and error distribution of the RCT or the RWD. We compute the difference in the RCT population over the first seven years (Figure 4).

times  <- seq(0.5, 7, by = 0.5)

A linear summary of the CATE is easier to report than a nonparametric surface. fusion_projection() projects every posterior draw of \(\tau\) onto a linear basis (Woody et al., 2021). The projection coefficients inherit a posterior distribution. Bayesian-bootstrap weights add the uncertainty about the covariate distribution. The basis columns are centred, so the intercept is the average CATE. For reference, we project the true CATE onto the same basis. In the simulation the CATE depends on the progesterone receptor and grade only.

Confounding and baseline deviation

The forests for \(c\) and \(d\) describe how the RWD differ from the RCT. A non-zero \(c(x)\) signals that the treatment contrast in the RWD is biased at \(x\). A non-zero \(d(x)\) signals that the RWD baseline differs from the RCT baseline. Figure 6 shows the posterior means for the RWD patients.

Error distribution

The argument error_dist selects the distribution of the error \(\varepsilon\). The four main options range from a single normal distribution to the nonparametric model of the paper.

error_dist Error model
"gaussian" One normal distribution, \(\varepsilon \sim N(0, \sigma^2)\), for both sources.
"source_gaussian" One normal distribution per source, \(\varepsilon \sim N(0, \sigma_s^2)\).
"shared_dp" One Dirichlet process mixture of normals for both sources (Henderson et al., 2020).
"source_hdp_scale" (default) A hierarchical Dirichlet process mixture of normals. The sources share the mixture components but have their own weights and scales \(\sigma_s\).

The normal models are fast and suit errors with a symmetric, unimodal shape. The mixture models adapt to skewed or multimodal errors. The default also lets the shape and the spread of the error differ between the sources. fusion_estimand() uses the fitted error distribution for the survival difference. The acceleration factor does not depend on it.

The default error model gives each source its own scale \(\sigma_s\). The fit stores their posterior draws in fit$dp_sigma_g, with the RWD first and the RCT second.

Interval censoring and other outcome types

The analysis above uses right-censored event times. FusionForest() also handles interval-censored event times and uncensored continuous outcomes.

Interval censoring

Interval censoring arises when an event is known to occur only between two visits. Three arguments describe such data: observed_left_time, observed_right_time and interval_censoring_indicator. The outcome type remains "right-censored". Each patient falls into one of three cases.

status interval_censoring_indicator Observation
1 0 Event at y.
0 0 Right-censored at observed_right_time.
0 1 Event in the interval from observed_left_time to observed_right_time.

The bounds use the same scale as y. At every iteration the sampler draws the unknown event times within their intervals. A call takes the following form, with left, right and ic holding the bounds and indicators:

fit_ic <- FusionForest(
  y = y, status = status,
  observed_left_time = left, observed_right_time = right,
  interval_censoring_indicator = ic,
  X_train_control = X, X_train_treat = X,
  treatment_indicator_train = A, source_indicator_train = S,
  outcome_type = "right-censored", timescale = "log"
)

The estimands and projections of the previous sections apply unchanged.

Continuous outcomes

The argument outcome_type = "continuous" fits an uncensored continuous outcome. The outcome then replaces \(\log T\) in the model, and status is not used. The CATE \(\tau\) is then the treatment effect on the outcome scale. The survival difference and the acceleration factor have no meaning for such outcomes. fusion_projection() with target = "cate" and the posterior draws of \(\tau\) remain available.
